# Profile Page

This folder owns the profile page and its styles.

- `ProfilePage.jsx` contains the profile page UI and editable fields.
- `ProfilePage.css` contains only profile-page styles and mobile rules.
- `index.js` exports `ProfilePage` for routing or role-based navigation.

Use the `role` prop with `crew`, `hospital`, or `traffic` to change the profile identity shown on the page.
