# Golden Hour — Minimal Web App Prototype

A responsive front-end prototype for Team Aurora's **Golden Hour: Smart Ambulance-to-ER Data Corridor**.

## Included
- Paramedic / ER role switch
- Emergency overview dashboard
- Golden-hour countdown
- Patient intake with fracture, chest pain and unconscious presets
- Browser voice-input demo
- GCS / NEWS2-style demo scoring and critical alert state
- Capability-matched hospital list with bed availability and ETA
- Transfer timeline and QR handoff demo
- Responsive mobile layout

## Run
Open `index.html` in a modern browser. No build step is required.

This is a front-end prototype. Live Firebase/WebSocket sync, Google Maps routing, OCR, authentication, real hospital bed feeds and production clinical validation are not connected yet.
